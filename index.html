Configura tu token de GitHub

Para sincronizar el progreso entre dispositivos necesitas un token de acceso personal de GitHub. Solo hay que hacerlo una vez por dispositivo.

  1. Ve a github.com/settings/tokens/new
  2. Nombre: entrenador-presupuesto
  3. Expiration: No expiration
  4. Marca el permiso: repo (primer checkbox grande)
  5. Pulsa Generate token y copia el resultado
Token invalido o sin permisos. Comprueba que marcaste el permiso repo.
